Featured projects

News RAG Agent

flagship project

A retrieval-augmented news agent that pulls from live RSS feeds, deduplicates and embeds articles, and answers questions with freshness-aware retrieval and cross-outlet bias comparison. Built to close a gap in vector database and RAG experience after finishing Datalyze.

  • Freshness-aware retrieval via Chroma metadata filtering on publish timestamps
  • Cross-outlet bias and framing comparison across sources covering the same story
  • Ingestion pipeline optimized from 30+ minutes to about 30 seconds using batching, parallelized downloads with ThreadPoolExecutor, and request timeouts
  • Currently exploring hybrid retrieval — BM25 plus dense vectors with reciprocal rank fusion
